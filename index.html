Current research summary +

Vibe coding turns natural-language intent into working software, but code generation alone does not give humans and agents a shared account of what they are building. As collaboration spans participants, components, and releases, design choices must remain understandable and open to revision. We argue that scaling human and AI coding collaboration requires a governable consensus layer. Agentic Consensus organizes collaboration around a versioned project-state model linking selected intent, structural commitments, executable artifacts, and evidence. Participants can clarify intent before implementation and coordinate proposed changes against commitments that humans can inspect and revise. Bidirectional synchronization connects intended changes to implementation and exposes conflicts or stale evidence as artifacts evolve. We implemented its review workflow in Consensus Control. Our research agenda asks how shared project state can preserve human understanding and control as agent contributions accumulate.

The research agenda

What should better review make possible?

01

Understand the commitment. Identify what a proposed change must preserve.

02

Judge the evidence. Check whether it is sufficient for this artifact version.

03

Keep decisions accountable. Choose a policy-compatible action with the right authority.

Our planned evaluation compares native review, a governance ledger, and relational project-state review. Their comparative benefits remain an open research question.

A few useful distinctions

Before you dive in.

Is consensus a vote between agents?+

Consensus means the currently authorized, versioned project state. It can contain contested claims and scoped waivers. Human or policy-defined authority determines which changes are admitted; agreement between agents does not establish truth or grant permission.

How does this relate to code review?+

It adds project-state review: which commitments a patch changes, which interpretation led to it, and whether the evidence still applies. Diffs, tests, and existing review practices remain useful and are linked to that shared context.

What can I run today?+

Consensus Control is an authenticated local review workspace with read-only GitHub PR import, commitment and source inspection, evidence requirements, and authorized decisions. Automated source analysis covers Python imports. Its executable realization path is bounded to a single Python import substitution; the broader research agenda is not a claim of general code synthesis.

Does approval merge my GitHub pull request?+

No. The GitHub connection is read-only. A decision updates local governed project state and its audit history. It does not push code or merge, create, or delete a GitHub pull request.
