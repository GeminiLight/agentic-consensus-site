# Website source moved

The AgenticConsensus website is now maintained together with the implementation
in [GeminiLight/AgenticConsensus](https://github.com/GeminiLight/AgenticConsensus),
under [website/](https://github.com/GeminiLight/AgenticConsensus/tree/main/website).

**The only official website is https://tianfuwang.tech/AgenticConsensus/.**

This repository is retained as the history of the original design. It is no
longer a website maintenance or publishing entrypoint. The previous
`/agentic-consensus/` and `/agentic-consensus-site/` Pages addresses redirect
to the official website, preserving query strings and section anchors.

For updates, work in the public AgenticConsensus repository. The old publishing
helper intentionally stops to prevent restoring an obsolete deployment.
